# Phase 6 – Project Testing

## 1. Testing Objective

The objective of testing is to verify that EduGenie functions correctly and provides the expected educational responses.

## 2. Features to be Tested

- Question and Answer
- Concept Explanation
- Quiz Generation
- Text Summarization
- Learning Path Recommendation
- Frontend and Backend Integration
- Input Validation

## 3. Testing Approach

The application will be tested by providing different inputs to each educational feature and checking the generated output.

## 4. Expected Result

Each feature should accept valid input and return an appropriate result.

Invalid or empty inputs should be handled properly.
