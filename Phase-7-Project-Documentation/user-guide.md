# User Guide

## 1. Open EduGenie

Start the FastAPI application and open the application in a web browser.

## 2. Select a Learning Task

Choose one of the following:

- Question & Answer
- Explain a Concept
- Generate Quiz
- Summarize Text
- Recommend Learning Path

## 3. Select Student Level

Choose:

- Beginner
- Intermediate
- Advanced

## 4. Enter Input

Enter your question, topic, or educational text.

## 5. Submit

Click the Submit button.

## 6. View Result

The generated educational result will appear in the Result section.
